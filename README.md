# HFFC-IEL
Hierarchical Fuzzy Feature Clustering With Iterative Ensemble Learning for Student Performance Prediction

Here gives an example for the prediction of G1 on the Math course dataset (Case 1). This can be easily extended to G2 and G3 or change the dataset to Por language course. The link to the datasets can be found in https://archive.ics.uci.edu/ml/datasets/student+performance
